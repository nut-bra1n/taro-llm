## 📖 Описание

taro-llm — это интерактивное веб-приложение, где вы задаёте вопрос картам Таро, а локальная LLM связывает выпавшие карты в единую интерпретацию. Приложение работает полностью локально и не требует интернета (кроме доступа к вашему локальному LLM серверу).

### Ключевые особенности:
- **Местный LLM** — используйте свою собственную модель через OpenAI-совместимый API
- **78 карт Таро** — полная колода с изображениями и данными
- **Киберпанк дизайн** — неоновые кнопки, глитч-эффекты, шрифт PressStart2P
- **WebSocket чат** — плавная потоковая выдача ответов от LLM
- **MCP интеграция** — инструменты для генерации карт Таро через FastMCP

### Как это работает:
1. Вы задаёте вопрос в текстовом поле
2. Приложение случайно выбирает три карты из колоды
3. LLM связывает карты в единую историю, учитывая их позиции и взаимное влияние
4. Результат отображается на экране с интерактивным [Markdown-парсером](https://github.com/MarketingPipeline/Markdown-Tag)

## 🚀 Установка

### 1. Клонировать репозиторий:
```bash
git clone https://github.com/nut-bra1n/taro-llm.git
cd taro-llm
```

### 2. Установить зависимости:
```bash
pip install -r requirements.txt
```

### 3. Настроить LLM сервер:
По умолчанию приложение ожидает локальный LLM на `192.168.0.13:1234`. Измените в `config.json`:
```json
{
  "LLM": {
    "HOST": "192.168.0.13",
    "PORT": 1234,
    "API_PREFIX": "/v1",
    "TEMPERATURE": 0.3
  }
}
```

### 4. Запустить приложение:
```bash
python main.py
```

## 💻 Использование

Откройте `http://localhost:8080` в браузере.

### Основные элементы интерфейса:
- **Текстовое поле** — задайте вопрос картам
- **Выпадающий список моделей** — выберите LLM для интерпретации
- **Кнопка 📩 send** — отправить запрос (с глитч-эффектом при наведении)
- **Кнопка ♻️ refresh** — сбросить и получить новые карты
- **Таймер** — анимация пока LLM генерирует ответ
- **Карточки Таро** — три случайные карты с изображениями

### Пример сеанса:
1. Введите вопрос: *"Что меня ждёт в ближайшие дни?"*
2. Нажмите **send**
3. Приложение выдаст три карты (например, *Шут*, *Колесо Фортуны*, *Сила*)
4. LLM свяжет их в историю: *"Вы на пороге нового начала... Случайные события изменят ваш путь, но ваша внутренняя сила поможет преодолеть любые испытания..."*

## 🛠️ Разработка

### Структура проекта:
```
taro-llm/
├── app/                   # aiohttp приложение
│   ├── llm.py             # LLM клиент
│   ├── routes.py          # API эндпоинты
│   ├── views.py           # WebSocket обработчики
│   ├── enums.py           # Роли сообщений (user, assistant, tool)
│   └── validators.py      # Pydantic валидация
├── mcp_server/            # MCP сервер для карт Таро
│   ├── server.py          # FastMCP сервер
│   ├── methods.py         # get_cards(), get_card()
│   └── dao.py             # DAO для работы с БД
├── data/db.sqlite3        # SQLite база данных (78 карт)
├── migration/             # Alembic миграции
├── config.json            # конфигурация
└── main.py                # точка входа
```

### Ключевые файлы:
- **`app/llm.py`** — класс `LLMClient` для общения с локальным LLM
- **`mcp_server/server.py`** — MCP сервер с инструментом `get_three_cards()`
- **`main.py`** — запускает веб-сервер + MCP сервер в отдельном потоке на порту 9000
